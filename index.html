Scenario 說明

          

            
              

                Scenario
                行為
                用途
              

            
            
              

                normal
                回傳完整 energy payload。
                驗證正常解析流程。
              

              

                no-total
                移除 payload 中的 total。
                測試 client fallback。
              

              

                http-500
                回傳 HTTP 500。
                測試錯誤處理。
              

              

                invalid-json
                回傳非合法 JSON 字串。
                測試 JSON parser 失敗情境。
              

              

                invalid-schema
                回傳欄位缺漏或型別錯誤的 JSON。
                測試 schema 驗證失敗情境。
              

              

                timeout
                延長回應時間，模擬 timeout。
                測試 timeout handling。
              

              

                custom
                回傳目前 Payload 編輯器中的內容。
                測試自訂 API 回應。
              

            
          


          
Query String 覆寫

http://127.0.0.1:3101/api/energy

http://127.0.0.1:3101/api/energy?scenario=custom

Action Config 說明

          

            
Action Config 可輸入 JSON，例如：

            
random: {"min":0,"max":100}
increment: {"step":1}
sine: {"base":100,"amplitude":10,"periodSec":30}

            
若 JSON 格式錯誤，系統會顯示中文錯誤訊息，且不會套用壞設定。

Bridge 流程概念

          
Modbus Register Table
        -> Mapping Rules
        -> HTTP API Payload
        -> Frontend / BMS API Client

        


        

          
預計功能

          
    
            
  • 以 Modbus register table 為來源。
    • 
            
  • 支援 register 對應到 JSON path。
    • 
            
  • 可產生 HTTP API response payload。
    • 
            
  • 可對應 BMS energy mapping。
    • 
            
  • 提供可調整的 JSON mapper。
