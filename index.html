位址模式說明


          

            
            
            
            

            

              

                
Request Address Base Mode：請求位址解析模式

                
這個設定用來決定：外部 BMS 或 Modbus Client 送進來的 request address，要如何對應到模擬器內部位址。


                

                  
Standard 0-based：request 0 = internal 0

                  
標準 Modbus 通訊位址模式。

                  
    
                    
  • 外部讀取 address 0 → 模擬器內部 address 0
    • 
                    
  • 外部讀取 address 1 → 模擬器內部 address 1
    • 
                  

                  
適合使用標準 0-based 位址的 Modbus client 或設備。

                


                

                  
Legacy 1-based：request 1 = internal 0

                  
相容部分 BMS 或舊式 Modbus 工具的位址習慣。

                  
    
                    
  • 外部讀取 address 1 → 模擬器內部 address 0
    • 
                    
  • 外部讀取 address 2 → 模擬器內部 address 1
    • 
                  

                  
如果你的 BMS 點表顯示第一點，但實際送出的 request address 是 1，請使用此模式。

                


                

                  簡單判斷
                  
    
                    
  • 如果 client 讀 address 0 才是第一點 → 選 Standard 0-based
    • 
                    
  • 如果 client 讀 address 1 才是第一點 → 選 Legacy 1-based
    • 
                  

                

              


              

                
Address Input Mode：位址輸入模式

                
這個設定用來決定：你在模擬器 UI 產生點位時，輸入的起始位址要怎麼解讀。


                

                  
Reference Address / 1-based 相容模式

                  
適合依照現場點表或一般 Modbus 工具的顯示位址輸入。

                  
    
                    
  • 輸入 300001 代表 Input Register 3x 的第一點。
    • 
                    
  • 也可以輸入 1 代表第一點。
    • 
                  

                  
此模式不建議輸入 0。

                


                

                  
Protocol Address / 0-based 模式

                  
適合工程測試或已知道實際 protocol address 的情況。

                  
    
                    
  • 輸入 0 代表模擬器內部 address 0，也就是第一點。
    • 
                    
  • 輸入 1 代表模擬器內部 address 1，也就是第二點。
    •
